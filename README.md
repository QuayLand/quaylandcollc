# Quay Land Co LLC landing page

Static HTML and CSS for the company landing page. No build, third-party scripts, or contact form service is required. Contact links open the visitor's email client.

## Local preview

Run `python3 -m http.server 8000` from this directory, then visit `http://localhost:8000`.

## GitHub Pages publication

This repository is `QuayLand/quaylandcollc`. Publish `main` from `/ (root)` in **Settings → Pages**. The `CNAME` file requests `quaylandcollc.com` as the custom domain. Configure that domain at GoDaddy after enabling Pages, following [GitHub's custom-domain instructions](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site). Keep existing email DNS records intact.
